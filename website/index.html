Keep translation where the reading happens

No copying into a web page, no deciding on a model first, no breaking off what you were reading.

  1. Select

    Select text in any app

    Mail, web pages, documents, chat messages and code comments — it all starts from the context you're already in.

  2. Summon

    Use your own global shortcut

    Or click the PopClip icon, or wire it into another tool through the URL scheme.

  3. Understand

    Copy an accurate, clean translation

    Tone, proper nouns, Markdown, paragraphs and code blocks are kept intact, with no commentary added.

Light isn't the same as thin.

Many target languages

Native throughout

A real Mac window, and your keys kept where the system keeps secrets.

Your text takes the route you choose.

LinguaDock ships no telemetry. Your text goes only to the service you chose yourself; with a local model, a translation never has to leave the machine at all. Your keys are handed to the system to keep, not to us — there is no "us" to send them to.

Not out yet.

When it is, it arrives the way the rest of it works: no account, no telemetry, and a translation service you chose yourself.
