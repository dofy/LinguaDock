原生 macOS 翻譯工具

選取，喚起，讀懂。

LinguaDock 把你在其他 App 中選取的文字直接帶進翻譯視窗。接上本機的 Ollama 或你自己的 OpenAI-compatible 服務，不用再繞遠路。

在 GitHub 查看專案 查看安裝方式

macOS 14+ · SwiftUI · MIT License

Notes

A good tool shortens the distance between a question and its answer.

It should stay close to the work, then disappear when the work continues.

⌘⇧T
LinguaDock 本機或雲端模型

好工具会贴近正在进行的工作，缩短问题与答案之间的距离；工作继续时，它便安静退场。

保留語氣與段落 複製譯文

把翻譯留在閱讀現場

不必複製到網頁，不必先決定模型，也不必打斷手上的內容。

  1. 選取

    在任何 App 中選取文字

    郵件、網頁、文件、聊天訊息和程式碼註解，都從當下的脈絡開始。

  2. 喚起

    使用自己的全域快速鍵

    也可以點一下 PopClip 圖像，或透過 URL Scheme 接進其他工具。

  3. 讀懂

    複製準確、乾淨的譯文

    保留語氣、專有名詞、Markdown、段落與程式碼區塊，不附加解釋。

翻譯服務不該變成產品綁定。

模型由你決定，LinguaDock 負責把它放到手邊。

◎

Ollama

接上本機模型。適合離線內容、私密文字，以及不想讓請求離開 Mac 的時候。

http://localhost:11434
↗

OpenAI-compatible

填寫自己的 Base URL、API Key 與模型名稱，接上相容的雲端或自架服務。

/v1/chat/completions

輕，不代表簡陋。

該出現時立刻出現，該記住的設定會記住，其餘時候保持安靜。

全域快速鍵

直接錄製並修改，不把按鍵寫死在提示裡。

PopClip

選取文字之後，從你熟悉的浮動選單打開 LinguaDock。

多語言目標

自動偵測原文，目標語言可隨時選擇並記住。

原生體驗

以 SwiftUI 建置，支援系統輔助使用與 macOS 鑰匙串。

你的文字，走你選的路線。

LinguaDock 不內建遙測。文字只會傳送到設定中指定的 API；用本機的 Ollama 時，翻譯請求不需要離開這台機器。API Key 依協定分開存在 macOS 鑰匙串裡。

從你自己的模型開始。

專案保持開源。複製、建置，然後設定一個你信任的翻譯服務。

git clone https://github.com/dofy/LinguaDock.git
cd LinguaDock
xcodegen generate
open LinguaDock.xcodeproj
