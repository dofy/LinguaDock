原生 macOS 翻译工具

选中，唤起，读懂。

LinguaDock 把其他 App 中选中的文字直接带进翻译窗口。连接本机 Ollama 或你自己的 OpenAI-compatible 服务，不再绕远路。

在 GitHub 查看项目 查看安装方式

macOS 14+ · SwiftUI · MIT License

Notes

A good tool shortens the distance between a question and its answer.

It should stay close to the work, then disappear when the work continues.

⌘⇧T
LinguaDock 本机或云端模型

好工具会贴近正在进行的工作，缩短问题与答案之间的距离；工作继续时，它便安静退场。

保留语气与段落 复制译文

把翻译留在阅读现场

不必复制到网页，不必先决定模型，也不必打断手上的内容。

  1. 选择

    在任意 App 中选中文字

    邮件、网页、文档、聊天消息和代码评论，都从当前上下文开始。

  2. 唤起

    使用自己的全局快捷键

    也可以点击 PopClip 图标，或通过 URL Scheme 接入其他工具。

  3. 读懂

    复制准确、干净的译文

    保留语气、专有名词、Markdown、段落与代码块，不附加解释。

翻译服务不该成为产品锁定。

模型由你决定，LinguaDock 负责把它放到手边。

◎

Ollama

连接本机模型。适合离线内容、私密文本，以及不想把请求发出 Mac 的时候。

OpenAI-compatible

填写自己的 Base URL、API Key 与模型名，接入兼容的云端或自托管服务。

该出现时迅速出现，该记住的设置会记住，其余时候保持安静。

全局快捷键

直接录制并修改，不把按键写死在提示里。

PopClip

选中文字后，从熟悉的浮动菜单打开 LinguaDock。

多语言目标

自动识别原文，目标语言可随时选择并记住。

原生体验

SwiftUI 构建，支持系统辅助功能与 macOS Keychain。

你的文本，按你的路线走。

LinguaDock 不内置遥测。文本只会发送到设置中指定的 API；使用本机 Ollama 时，翻译请求无需离开本机。API Key 分协议保存在 macOS Keychain。

从自己的模型开始。

项目保持开源。克隆、构建，然后配置你信任的翻译服务。

git clone https://github.com/dofy/LinguaDock.git
cd LinguaDock
xcodegen generate
open LinguaDock.xcodeproj
